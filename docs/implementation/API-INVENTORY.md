## Phase 00 source follow-up: collections and NAS side effects

- [BookMetadataUpdater.java lines 247–331](https://github.com/grimmory-tools/grimmory/blob/v3.5.0/backend/src/main/java/org/booklore/service/metadata/BookMetadataUpdater.java#L247-L331) shows nonempty authors/categories under `REPLACE_WHEN_PROVIDED` can **replace entire collection** when mergeCategories=false; explicit merge plan per field and preview is mandatory. Empty authors/categories under safe mode preserve instead of clearing, but `clearFlags=true` forces clear unless locked. Moods/tags have separate merge switches; do not silently treat `mergeCategories` as all three. Exact API exposure for moods/tags remains to be checked.
