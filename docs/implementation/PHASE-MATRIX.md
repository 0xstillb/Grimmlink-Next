- **Phase08 development close:** `DEV_CHECKS_PASS_WITH_DEFERRED_RISKS` requires offline deliverables, targeted checks, CI on the exact implementation SHA, and a matching result/handoff. - **Phase09 staging entry:** requires a disposable staging environment, test data, backup, configured owner session, read-only NAS fixture and test readers. Missing staging resources block staging execution, not the Phase08 development close.
- **Production release:** requires Phase09 scenario evidence, one consolidated independent security review and fixes, proven rollback and explicit owner approval.
