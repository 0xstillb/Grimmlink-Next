The review summary never infers compatibility or impact, never authorizes an update, and cannot install; the Update Center explicitly says no feed was fetched.
- Added a fixed allow-listed support-bundle preview with SHA-256 over the canonical report JSON. A one-hour timer clears only the in-page preview; copied clipboard text cannot be revoked. The bundle collects no server logs, device identifiers, book data or personal notes.
- Added `SafeLogBuffer`, a bounded in-memory Pino destination that reapplies the final safe-line allow-list and supports level, event-code and correlation-ID filters. Defaults are 500 entries / 1 MiB / 24 hours; hard limits are 10,000 entries / 8 MiB / at most 24 hours. It is not wired into the running adapter, authenticated routes or Control Center viewer, and is not persistent.
